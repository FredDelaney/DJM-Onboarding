# Document export fonts

Static Noto Sans Regular/Bold and Noto Serif Regular from [notofonts/noto-fonts](https://github.com/notofonts/noto-fonts/tree/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf).

Upstream revision: `ffebf8c1ee449e544955a7e813c54f9b73848eac`. Original files are unmodified. The bundled SIL Open Font License is in `OFL.txt`.

Fetched only when the PDF exporter is used. These files support extended Latin, Greek and Cyrillic names without relying on a third-party font host at export time.
