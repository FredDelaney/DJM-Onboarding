# AI architecture

DJM uses bounded intelligence capabilities behind common authentication, retrieval, schemas, provenance, approvals and audit.

- Deterministic: dates, hard constraints, freshness, permissions and priority rules
- Structured extraction: strict validated output retained as proposed facts
- Retrieval: SQL for exact facts, full text for lexical memory, vectors only for semantic material, typed edges for relationship paths and events for chronology
- Reasoning: configurable provider/model, used only after authorised evidence assembly
- Consequences: low may automate; medium may require review; high always requires approval

External content is untrusted. No prompt can expand database scope. AI output never silently changes contractual or verified truth.
