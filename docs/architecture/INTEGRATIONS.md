# Integrations

Integration adapters own provider-specific authentication, cursors, external IDs and payload mapping. Domain code consumes provider-neutral records.

Current real integrations: Supabase, Web Push, secure Storage and existing share/PDF flows. Outlook/Calendar, official WhatsApp Business, model providers and licensed football/video providers remain configuration-dependent. The product must show `Not connected` until credentials and permissions exist; personal WhatsApp scraping and unauthorised Transfermarkt scraping are prohibited.
