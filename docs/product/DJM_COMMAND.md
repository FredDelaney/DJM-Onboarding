# DJM Command

Command is the default staff surface. It ranks meaningful decisions rather than displaying vanity dashboards.

Every recommendation shows subject, recommendation (`Act`, `Review`, `Plan`, `Hold`), reason, evidence, urgency, confidence, owner, next action and timestamp. Rules are transparent and configurable. `Hold` is a valid, valuable recommendation when DJM recently acted and no new evidence exists.

The system detects and drafts; a human approves consequential work.
