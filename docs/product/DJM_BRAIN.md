# DJM Brain

Brain is an authorised query interface, not an unconstrained chatbot.

Retrieval order: authorise scope → structured SQL/full-text/graph/event/vector retrieval as appropriate → assemble evidence → model if needed → cite and expose uncertainty. If no reliable fact exists, Brain says so.

The initial product remains useful without a model provider through deterministic questions and live structured briefs. Provider-backed reasoning is feature flagged and requires configured models, audit, cost/latency logging and evaluation.
